# Translations - GNOME Shell Cast

This directory contains all translation files for the GNOME Shell Cast extension.

## Directory Structure

```
po/
├── gnome-shell-cast@oxygenws.com.pot  # Translation template (master source)
├── ar.po      # Arabic       ├── fr.po      # French
├── bg.po      # Bulgarian    ├── hi.po      # Hindi
├── bn.po      # Bengali      ├── id.po      # Indonesian
├── de.po      # German       ├── pt_BR.po   # Portuguese (Brazil)
├── es.po      # Spanish      ├── ru.po      # Russian
├── fa.po      # Persian      ├── ur.po      # Urdu
│                             └── zh_CN.po   # Chinese (Simplified)

English is the source language: the msgids are already English, so gettext
falls back to them and no English .po file is needed.
```

**Name the file after the bare language code** (`es`, `fr`, `ru`) unless the
regional variants genuinely differ (`pt_BR` vs `pt_PT`, `zh_CN` vs `zh_TW`).
gettext looks up `es_MX`, then falls back to `es` — but never sideways to
`es_ES`, so a region-suffixed file only reaches users in that one region.

## Files

### `.pot` (Portable Object Template)
- **gnome-shell-cast@oxygenws.com.pot** - Master template extracted from source code
- Contains all translatable strings in English
- Auto-generated by `make extract-translations`
- Never edit this file manually

### `.po` (Portable Object Files)
- One per language, listed above
- Edit these files to add/update translations
- Can be edited with any text editor or tools like Poedit

## Workflow

### 1. Extract New Strings from Source
When new translatable strings are added to the extension:

```bash
make extract-translations
```

### 2. Update All Translation Files
To sync existing .po files with new strings in .pot:

```bash
make update-translations
```

### 3. Edit Translations
Open a .po file and add translations for each msgid:

```bash
# Using text editor
nano extension/gnome-shell-cast@oxygenws.com/po/de.po

# Or use Poedit GUI
poedit extension/gnome-shell-cast@oxygenws.com/po/de.po
```

### 4. Compile, Install and Test
`.po` files must be compiled to `.mo` with msgfmt. `make install-extension`
runs `make compile-translations` for you; `make ego-zip` compiles them into
the uploaded bundle via `gnome-extensions pack --podir`:

```bash
make install-extension
```

Change system language in Settings → Region & Language and verify translations appear.

## .PO File Format

Each entry looks like:
```po
#: extension/gnome-shell-cast@oxygenws.com/lib/castMenu.js:52
msgid "Stop casting"
msgstr "Casting stoppen"
```

- `#:` - Source file and line number reference
- `msgid` - Original English text
- `msgstr` - Translated text

## Translation Guidelines

**Start with the `translations` skill.** The wording should match the rest of
the GNOME desktop, so terms are looked up in GNOME's own catalogues rather than
invented; the skill has the lookup script and the sources.

### Glossary — where each recurring term comes from

Language-independent on purpose: look the term up in the module named here, in
whatever language you are translating into.

| Term in our strings | Take the wording from |
|---|---|
| Preferences, Close, Copy, About, Version %s | `libadwaita`, `gtk40` |
| Top bar, Quick settings, Window, Connect, Disconnect | `gnome-shell` |
| Screen, Resolution, Devices, Volume, Mute | `gnome-control-center-2.0` |
| Framerate (as *frame rate*), bitrate, stream, audio | `gstreamer-1.0`, `gtk30` |
| General, Automatic | `gnome-control-center-2.0` |
| Video, Pixel format | `gtk40`, `gst-plugins-good-1.0` |
| Encoder, Encoding | `gst-plugins-*` — the *video* sense, see below |
| Cast, Chromecast, HLS, D-Bus, GNOME, NV12, I420 | not translated — keep as-is |

Three that catch people out: German *About* is `Info`, not `Über`; *Volume*
means `Lautstärke` here, not the disk-utility `Datenträger`; and *Encoding* in
`gtk40` is **character** encoding, which is a different word from video encoding
in several languages (Russian `Кодировка` vs `Кодирование`). Take it from a
`gst-plugins-*` string that is about video, not from `gtk40`.

1. **Keep format placeholders**
   ```po
   msgid "Version %s"
   msgstr "Versión %s"  # Keep the %s!
   ```

2. **Preserve whitespace**
   - Don't add or remove spaces/newlines
   - Quotes must match the original

3. **Use proper quotation marks**
   - Use language-appropriate quotes: German „" or « », Persian « »
   - Keep original structure intact

4. **Pluralization** (if needed)
   ```po
   msgid "One file"
   msgid_plural "%d files"
   msgstr[0] "Una archivo"
   msgstr[1] "%d archivos"
   ```

5. **Context** (if translation is ambiguous)
   ```po
   msgctxt "Cast status"
   msgid "Casting"
   msgstr "Transmitiendo"
   ```

## Adding a New Language

1. Create the .po file from the .pot template:
   ```bash
   msginit -i extension/gnome-shell-cast@oxygenws.com/po/gnome-shell-cast@oxygenws.com.pot \
           -o extension/gnome-shell-cast@oxygenws.com/po/it.po \
           -l it --no-translator
   ```

2. Edit the file header with translator info:
   ```po
   "Language: it\n"
   "Last-Translator: Your Name <your.email@example.com>\n"
   "Language-Team: Italian <team@example.com>\n"
   ```

   The team page at <https://l10n.gnome.org/teams/it/> has the language's
   correct `Plural-Forms` line.

3. Translate all strings
4. Install extension: `make install-extension` (compiles translations first)
5. Test by changing system language in Settings → Region & Language

## Compiled Files

The `.mo` (Machine Object) files are compiled into the extension's `locale/`
tree, named after the `gettext-domain` from `metadata.json`:
```
~/.local/share/gnome-shell/extensions/gnome-shell-cast@oxygenws.com/locale/
├── ar/LC_MESSAGES/gnome-shell-cast@oxygenws.com.mo
├── de/LC_MESSAGES/gnome-shell-cast@oxygenws.com.mo
└── …one per .po file
```

These are generated by `make compile-translations` (msgfmt) and are not
checked into git. Never edit them directly.

## Tools

### Command-line
- `xgettext` - Extract strings
- `msginit` - Create new .po from .pot
- `msgfmt` - Compile .po → .mo
- `msgmerge` - Update .po from .pot

### GUI Applications
- [Poedit](https://poedit.net/) - Free and commercial versions
- [Gtranslator](https://wiki.gnome.org/Apps/Gtranslator) - GNOME's official editor
- [Lokalize](https://userbase.kde.org/Lokalize) - KDE translation tool
- VS Code with gettext extensions

## Translation Statistics

English is the source language, so it needs no .po file. Every other language
in this directory is fully translated - keep it that way when new strings land.

```bash
for f in extension/gnome-shell-cast@oxygenws.com/po/*.po; do
    printf '%-8s ' "$(basename "$f" .po)"; msgfmt -c --statistics -o /dev/null "$f"
done
```

`msgfmt -c` also catches placeholder mismatches and a wrong plural-forms header.

## Testing Translations

1. Install extension: `make install-extension` (this compiles all translations)
2. Restart GNOME Shell (Ctrl+Alt+F2, `r`, Enter)
3. Change system language in Settings → Region & Language
4. Verify translations appear in the UI
